# Запрос к срезу УНФ

Когда нужны данные базы, сразу вызывай `run_query`. Не выдумывай строки.

Объекты: Справочник.Номенклатура, Документ.РасходнаяНакладная, РегистрСведений.ЦеныНоменклатуры, РегистрНакопления.Продажи.

Продажи за период:

```
ВЫБРАТЬ
	Продажи.Номенклатура.Наименование КАК Номенклатура,
	Продажи.КоличествоОборот КАК Количество,
	Продажи.СуммаОборот КАК Сумма
ИЗ
	РегистрНакопления.Продажи.Обороты КАК Продажи
```

Цены по параметру. В `params` передай `{"ВидЦен": "Розничная"}`:

```
ВЫБРАТЬ
	Цены.Номенклатура.Наименование КАК Номенклатура,
	Цены.Цена КАК Цена
ИЗ
	РегистрСведений.ЦеныНоменклатуры.СрезПоследних(, ВидЦен = &ВидЦен) КАК Цены
```

Ссылку в параметр клади объектом `{type, uuid}` из предыдущего ответа. Дату — строкой `2026-10-20`.

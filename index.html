    Настройки
    Прямой XHR, без прокси. Ollama Cloud: https://ollama.com/v1 + путь /v1/chat/completions или стиль Ollama /api/chat.
    Файл config.json в рабочей области агента (через мост 1С). В dev ключ может подставиться из OLLAMA_API_KEY.
    Инструменты — только через DOM-мост 1С (#harness-1c-bridge). В браузере платформу имитирует JS (stub-1c-platform.js); в обработке — ?backend=1c и harnessDeliverResponse.
    Чем выше, тем разнообразнее ответ.
    Для индикатора заполнения под полем ввода (токены).
    Цвета 1С Такси; подложка чата с логотипом — как у крабобота. Поле ввода — капсула.
